# BeatBox

A Java Swing desktop application for creating and playing simple drum beats using a 16×16 step sequencer.

The project uses **Java Swing** for the graphical interface and **Java MIDI API** (`javax.sound.midi`) for sound generation and playback.

### Features

* 🎵 16 drum instruments
* 🥁 16-step beat sequencer
* ▶️ Start and stop playback
* ⏩ Increase and decrease tempo
* 💾 Save beat patterns to a file
* 📂 Load previously saved patterns
* 🔁 Continuous loop playback
* 🎹 MIDI-based sound generation

### Technologies

* Java
* Java Swing
* Java MIDI API
* Object Serialization
* Event-driven programming

This project was created as a Java learning project to practice **GUI development, event handling, file I/O, serialization, and MIDI programming**.
